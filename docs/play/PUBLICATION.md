## Signing configuration

In [repository environments](https://github.com/sayac007/Kinderwelt/settings/environments),
configure **`release`**, limit deployment to `main`, and add the required human
reviewer if supported by the account. The source guard also allows only manual
runs on `main`; a workflow environment name alone does not prove that protection
rules are configured. The environment API is not accessible to this client.

Create/retain your upload key locally using [the existing instructions](../android.md)
and keep an encrypted offline backup. No operator key is generated by this work.
Set these environment **Secrets**, not ordinary variables or repository files:

| Secret | Value supplied by the operator |
|---|---|
| `KINDERWELT_UPLOAD_KEYSTORE` | `base64:` followed by the existing keystore's Base64 contents |
| `KINDERWELT_UPLOAD_ALIAS` | Alias inside that keystore |
| `KINDERWELT_UPLOAD_STORE_PASSWORD` | Keystore password |
| `KINDERWELT_UPLOAD_KEY_PASSWORD` | Key password |

The operator’s asset statement is now recorded in `release-metadata.json`:
**“Alle Rechte vorbehalten, soweit Schutzrechte bestehen.”** Environment variable
**`KINDERWELT_ASSET_LICENSE`** is an optional explicit override.
The existing software, music, font and upstream notices retain their own terms;
this value is not a blanket replacement for them. Publisher/contact can optionally
be overridden with `KINDERWELT_PUBLISHER` / `KINDERWELT_SUPPORT_EMAIL`; empty
variables correctly fall back to the supplied metadata file.
