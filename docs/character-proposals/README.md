# Öffentliche Spielfiguren

Nova, Lumi, Karo, Tavi, Zora, Flocke und das Eichhörnchen sind frei wählbar. Jede Figur bietet Normal-, Helden-, Alien-, Astronauten- und Forscherkleidung.

Die sechs neuen Figuren sind eigenständige Fantasiegestaltungen. Ihre einzige Originaldatei ist [der transparente Atlas](../../art/public/characters/neutral-cast.png?raw=true); Regionen stehen im zugehörigen Katalog. Das Eichhörnchen liegt unter `assets/quest/`. Es werden keine doppelten PNGs oder Downloadarchive hier benötigt. Varianten: [variants.md](../variants.md).
