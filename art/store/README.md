# Store placeholder

`silhouette.svg` is an original geometric vector written for the store-render
script: three shapes, no photograph, reference person, family asset or external
resource. The operator-selected conditional rights reservation is recorded in
`ASSETS_LICENSE.md`; this provenance note makes no independent protection claim. It is a clearly
fictional placeholder for the optional local-image feature, not a new bundled
playable character. No private input is accepted by the store renderer.

Store outputs go to ignored `build/store/`, never to this source directory.
The operator can commission a replacement in a separately reviewed change;
never substitute a real person/child photo for the custom-image store screenshot.
